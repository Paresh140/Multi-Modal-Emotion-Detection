Multi-Modal Emotion DetectionA deep learning framework for Multimodal Emotion Recognition (MER) that fuses acoustic features from Wav2Vec 2.0 and semantic features from RoBERTa to classify emotions from human speech.🚀 OverviewTraditional emotion recognition often relies on a single modality, which can miss crucial context. This project implements a Late-Fusion architecture to capture both "how" something is said (prosody) and "what" is being said (semantics).By combining these signals, the model achieves a significant performance boost over single-modality baselines.🏗️ ArchitectureThe system utilizes two state-of-the-art transformer-based encoders:Audio Branch: Wav2Vec 2.0 (facebook/wav2vec2-base) processes raw waveforms, with selective fine-tuning of the top 4 transformer layers.Text Branch: RoBERTa-base (roberta-base) extracts semantic embeddings from transcriptions using the [CLS] token.Fusion Head: A late-fusion strategy concatenates both 768-dimensional embeddings into a 1,536-dimensional vector, followed by a two-layer MLP for classification.📊 Dataset: CREMA-DExperiments were conducted on the CREMA-D dataset:Samples: 7,442 audio clips.Speakers: 91 professional actors (48 ethnic backgrounds, balanced gender split).Classes: Angry, Disgust, Fear, Happy, Neutral, Sad.Evaluation: Strict Speaker-Independent 5-fold cross-validation (71/14/14 split) to prevent identity leakage.📈 Performance ResultsThe multimodal approach consistently outperforms unimodal baselines:ModelTest AccuracyMacro-F1Audio-only (Wav2Vec 2.0)60.1%0.590Text-only (RoBERTa)65.9%0.650Multimodal Fusion (Best Fold)69.79%0.696
